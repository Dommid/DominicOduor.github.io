01 / THE CHALLENGE

Problem & context

The project called for a structured assessment of the client’s security posture, bringing together application, network, client-side, and organizational security workstreams.

02 / THE APPROACH

How I approached it

01

Scope & methodology

Worked within a client-authorized engagement and organized web testing using the OWASP Web Security Testing Guide.

02

Reconnaissance & validation

Used Kali Linux, Burp Suite, and command-line reconnaissance tools to investigate application behavior and configuration in the authorized scope.

03

Risk-based analysis

Categorized observations, distinguished confirmed issues from inconclusive tests, and considered business impact and remediation priority.

04

Collaboration & reporting

Coordinated with the broader capstone team through sprint meetings and summarized testing methodology and recommendations.

03 / OUTCOME

What it demonstrated

Produced web application testing documentation and contributed to the cross-functional assessment deliverables. Specific findings and client artifacts are intentionally excluded from this public portfolio.
